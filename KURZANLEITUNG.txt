SO EINFACH GEHT ES

Auf der Kursseite unten auf „Kurs verwalten“ klicken:
https://kowerk-edu.github.io/TG11_Physik/verwaltung/

NAME ÄNDERN
1. „Kursname ändern“ klicken.
2. Das Wort durch TGE, TGEI oder einen anderen Namen ersetzen.
3. „Commit changes“ klicken und bestätigen.
Fertig: Der Name ändert sich auf der ganzen Kursseite.
Die PDF-Inhalte und die Internetadresse bleiben erhalten.

NEUEN ORDNER ANLEGEN
1. „Ganz oben“ für eine Oberkategorie wählen.
   Für einen Unterordner zum Beispiel „Kinematik“ wählen.
2. Den neuen Namen eingeben, zum Beispiel „Freier Fall“.
3. „Ordner auf GitHub anlegen“ klicken.
4. „Commit changes“ klicken und bestätigen.
Die kleine Datei ordner.txt ist bereits vorbereitet. Einfach so lassen.

PDF HOCHLADEN
1. Bei „PDF hochladen“ den Zielordner wählen.
2. „PDF auf GitHub hochladen“ klicken.
3. Eine oder mehrere PDFs in das GitHub-Fenster ziehen.
4. „Commit changes“ klicken.
Fertig. Die PDFs erscheinen von allein auf der Kursseite.

Nach dem Speichern ein paar Minuten warten und die Kursseite neu laden.
Für GitHub brauchst du dein Konto mit Schreibzugriff auf das Projekt.

MIT EINEM BEFEHL IM PROJEKTORDNER
Name ändern:       python3 kurs.py name TGE
Ordner hinzufügen: python3 kurs.py ordner "03 Kinematik/05 Freier Fall"
PDF hinzufügen:    python3 kurs.py pdf "Arbeitsblatt.pdf" "03 Kinematik/05 Freier Fall"
Menü starten:      python3 kurs.py

Diese Befehle speichern auf deinem Computer. Danach die Änderungen mit
GitHub Desktop oder git commit und git push hochladen.
