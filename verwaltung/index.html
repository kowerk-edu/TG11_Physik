Name ändern, Ordner anlegen, PDFs bereitstellen. Wähle einfach aus, was du machen möchtest.

PDF hochladen

  2. PDF auf GitHub hochladen ↗

    Ziehe eine oder mehrere PDFs in das geöffnete Fenster. Oder klicke dort auf choose your files (Dateien auswählen).

  3. Unten auf Commit changes (Änderungen speichern) klicken. Fertig!

Die PDF erscheint automatisch im gewählten Ordner. Du musst keinen Link und keinen Code ergänzen. Das geht auch mit Bildern, Videos und HTML-Übungen.

Themen ordnen

Neuen Ordner anlegen

  1. Für eine Oberkategorie wählst du „Ganz oben“. Für eine Unterkategorie wählst du zum Beispiel „Kinematik“.

  2. Gib einen Namen ein.

  3. Ordner auf GitHub anlegen ↗

    Die kleine Platzhalterdatei ist schon vorbereitet. Auf GitHub auf Commit changes klicken und das Speichern bestätigen. Der Ordner erscheint danach im Kurs.

Neue Ordner werden automatisch hinten einsortiert. Nach dem Speichern kannst du diese Seite neu laden und den neuen Ordner für einen PDF-Upload auswählen.

Ein Name für den ganzen Kurs

Kurs umbenennen

Aktueller Name: Kurs

  1. Kursname ändern ↗
  2. Das vorhandene Wort durch den gewünschten Namen ersetzen, zum Beispiel TGE oder TGEI.
  3. Auf Commit changes klicken und das Speichern bestätigen. Der Name wird auf der ganzen Kursseite übernommen.

Auch Kopfzeile, Begrüßung, Fußzeile und Impressum verwenden den neuen Namen. Der Text innerhalb bereits vorhandener PDFs bleibt erhalten.
